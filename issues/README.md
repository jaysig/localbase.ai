# LocalBase Issues

This folder tracks issues and bugs in the LocalBase framework. Eventually this will sync to GitHub Issues.

## Issue Naming Convention

```
NNN-short-description.md
```

Examples:
- `001-electron-wrong-workspace.md`
- `002-connector-sync-fails.md`
- `003-viz-registry-race-condition.md`

## Issue Template

```markdown
# Issue #NNN: Short Description

**Status:** 🔴 Open | 🟡 In Progress | 🟢 Resolved | 🔵 Won't Fix
**Priority:** Critical | High | Medium | Low
**Created:** YYYY-MM-DD
**Reporter:** Name or "Other Claude"

## Problem

Brief description of the issue.

## Evidence

Screenshots, error messages, logs, etc.

## Root Cause

Technical explanation of why this happens.

## Impact

What this breaks or affects.

## Solution

Proposed fix or approach.

## Files Involved

List of files that need to be changed.

## Next Steps

- [ ] Task 1
- [ ] Task 2
- [ ] Task 3
```

## Status Indicators

- 🔴 **Open** - Needs investigation or fix
- 🟡 **In Progress** - Actively being worked on
- 🟢 **Resolved** - Fixed and tested
- 🔵 **Won't Fix** - Not addressing (document why)
