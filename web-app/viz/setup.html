💡 LocalBase Setup

⚠️ Framework mode detected - You need to create a workspace to get started.

1 Create a workspace

Create a new directory and initialize your workspace:

# Create workspace in parent directory
cd ..
mkdir my-workspace
cd my-workspace

# Copy framework files (or clone from your fork)
cp -r ../localbase.ai/* .
npm install
npm start

2 Open your workspace

Visit http://localhost:3000 - you'll see your workspace dashboard with no data yet. Add connectors to get started.
